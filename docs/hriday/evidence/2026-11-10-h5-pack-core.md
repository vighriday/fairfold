# H5 local Pack Station core

Date: 10 November 2026 IST
Branch: `Hriday`
Scope: local implementation only; no real PayPal or Render acceptance

## Implemented

- Merchant-owned `GET /api/orders/:id/pack`, multipart photo upload, override and seal routes.
- JPEG/PNG validation, 12 MB per-file and six-file limits, EXIF freshness checks and supported photo labels.
- Image normalization and content-addressed storage through the existing BlobStore; cross-order reuse is rejected within the merchant.
- Pack state includes active product batches, latest attestation, inspection rule and blocker codes.
- Override clears only the latest attestation mismatch and records an `override` ledger entry.
- Seal locks the order, validates stock and ownership, decrements inventory once, creates a shipment, appends `sealed`, commits, then queues `tracking.push`.
- Tracking worker performs up to three deterministic PayPal attempts, persists only the tracker/status projection, appends `tracking_pushed`, and raises a bounded failure alert.
