## Primary-source checks

Used the current official [tracking operation](https://developer.paypal.com/api/orders/v2/orders-track-create) and Orders **2.36** schema already digested in [Orders evidence](2026-11-09-h2-orders.md). The operation lists a flat body and returns order purchase_units.shipping.trackers. Its examples show a composite tracker ID; implementation selects only IDs actually returned and also permits a unique opaque ID. The operation does not list PayPal-Request-Id among its headers, so the required source header is sent without assuming undocumented 5xx idempotency.

Checked [Disputes schema](https://developer.paypal.com/api/customer-disputes/v1/schema.json), version **1.12**, SHA-256 `fee5e04ab606f8961b95744e65c4189fc7c4613e79ba2f944d2deab79e834330`.
