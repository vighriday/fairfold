# H7 shopper policy evidence

The shopper workflow is implemented in `@fairfold/shopper` as a provider-injected policy boundary:

- searches the catalogue and retrieves store reports;
- skips caution stores;
- pauses before ordering from a store that is not verified;
- passes `context.sandbox = true` to order creation and capture;
- returns the PayPal approval URL and pauses;
- refuses capture unless an explicit human `paypal-approved` decision is supplied;
- records only sanitized transcript events.

The workflow does not claim that a model ran, that a human approved payment, or that PayPal captured an order. Those remain external/runtime gates.
