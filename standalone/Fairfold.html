02 · One order, end to end

Four moments.
One witness.

01
Before the buyer paysStore Report

A store report beside the PayPal button: verifiable facts, the store’s fulfilment record and verified-buyer reviews, each claim linked.

02
Before the merchant shipsBuyer Signal

A band — green, yellow, red, or grey for new buyers — with its reasons and a recommended action. Never “cancel”. The decision stays with the merchant.

03
At the packing tableProof Ledger

An AI checks the item in the photos against the PayPal order, seals the evidence in a hash chain, and pushes tracking to PayPal.

04
If a dispute opensDispute Room

A PayPal webhook wakes the Dispute Agent. It builds the evidence pack that dispute reason needs and files it through the Disputes API once the merchant approves — or says when the case can’t be won.

04 · Five model-backed components, one rule

Code computes every score. The AI only sees, reads, drafts and explains.

ComponentThe modelCode decides
01 Evidence Agent Describes each visible item, reads size and batch labels and the courier label, lists visible defects. Match, mismatch or could-not-verify. Seal blocks anything but a match unless the merchant overrides.
02 Complaint Reader Fills a fixed taxonomy from complaint text and photos: category, component, failure mode, severity. Embedding, grouping and every statistic behind a shared-cause alert.
03 Dispute Agent Writes the narrative from a supplied fact list only. The recommendation, the evidence type and the files, from a decision table. The merchant approves every submission.
04 Review Themer Names themes in verified-payment reviews and assigns review ids to them. Counts, ratings, which themes appear, and the citation behind each one.
05 Message Drafter Drafts the subject and body of a buyer message. Which buyers, which wording level, and that nothing sends without approval.
NO AUTO-ANYTHING

No auto-cancel, no auto-refusal, no auto-filed dispute response.

GREY, NEVER RED

A new buyer with no history gets grey, “not enough data”, never red.

QUOTED DATA

Reviews, web pages and buyer messages are untrusted input, never instructions.
